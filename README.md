## Обработка естественного языка

### Первая работа. Предобработка текста

**Постановка задачи:**

Требуется прочитать текст на русском языке из файла и вывести все пары соседних слов, которые:

- имеют имена существительные или имена прилагательные на первом или втором месте (всего четыре возможные комбинации);
- совпадают по роду, числу и падежу.

Все пары следует выводить в виде лемм. Например, если исходная пара имела вид «необычайных университетов», то должна быть выведена пара «необычайный университет». Пары следует определять после сегментации и токенизации текста.

```bash
# запуск утилиты
py -u lab1.py < "path_to_your_file.txt"
```

**Идея решения**

1. Текст сегментируем --> получаем список предложений.
2. Каждое предложение токенизируем --> получаем токены внутри каждого предложения.
3. Соседние токены парсим и определяем, что они относятся к существительным и прилагательным.
4. Для всех трактовок первого и второго токена, составляем пары всех возможных комбинаций трактовок комбинаций.
5. У каждой трактовки своя частота использования, ищем такую пару трактовок, чтобы вероятность их совместного использования была максимальной (P_токена1 * P_токена2). Если вероятности у каких-либо из пар одинаковые, то берем пару в соответствии с критерием (от более приоритетного к менее) (1) Adjective, Noun; (2) Noun, Adjective; (3) Adjective, Adjective; (4) Noun, Noun.
6. В результате предыдущего шага получаем единственную комбинацию трактовки токенов (которые пропарсили через морфологический анализатор). Каждый из токенов в паре приводим к нормальной форме и выводим.

***Анализировать будем "Преступление и наказание" 1 глава 1 часть.***

### Вторая работа. Векторное представление слов

**Постановка задачи:**

Используя import gensim, необходимо реализовать вычисление десяти самых близких по смыслу слов, находящихся в окрестности результата операций сложения и вычитания в векторной модели. Каждому студенту преподавателем будет дана пара слов и необходимо найти такую линейную комбинацию исходных слов, чтобы в результате вычислений заданная пара попадала в первую десятку. Задание предполагает работу только с именами существительными (учащийся может использовать для решения тоже только имена существительные).

**Дано:** предобученные векторы в файле cbow.txt, размерность (~180000, 300).

```bash
# запуск утилиты
py -u lab2.py
```

**Предварительно:**

```python
# фильтруем слова, оставляем только существительные
pat = re.compile("(.*)_NOUN")
word2vec = gensim.models.KeyedVectors.load_word2vec_format('cbow.txt', binary=False)
nouns = [
    word for word in word2vec.index_to_key
    if pat.fullmatch(word)
]

model = gensim.models.KeyedVectors(vector_size=word2vec.vector_size)
model.add_vectors(nouns, word2vec[nouns])
```

**Идея решения**

1. Пользователь вводит два целевых слова, для которых нужно подобрать линейную комбинацию из других слов в векторном пространстве.
2. Для каждого целевого слова находим 100 наиболее близких по смыслу слов с помощью метода most_similar().
3. Объединяем полученные списки, удаляем дубликаты (при помощи свойств множества), целевые слова и слова из списка исключений ({target1, target2, *exclude}).
4. Формируем список из оставшихся слов, сортируем его для обеспечения воспроизводимости результатов. При необходимости случайным образом перемешиваем список с возможностью фиксации random_state.
5. Формируем все возможные сочетания из двух слов-кандидатов с помощью combinations().
6. Для каждой пары перебираем три варианта линейной комбинации векторов: (1) A + B; (2) A − B; (3) B − A.
7. Для каждой линейной комбинации с помощью most_similar() вычисляем 10 ближайших по косинусному сходству слов к линейной комбинации.
8. Проверяем, входят ли оба целевых слова в полученную десятку. Если условие выполняется, выводим найденную линейную комбинацию и список ближайших слов с косинусными сходством, после чего завершаем поиск.
9. Если условие не выполняется, переходим к следующей комбинации (отслеживать можно при помощи прогресс-бара).

### Третья работа. Маскирование слов

корректно составленном предложении на русском языке.

### Четвертая работа. Генерация текста

**Постановка задачи:**

Используя модель RuGPT от Сбера (можно брать другие модели, но они должны быть foundation, т. е. не должны содержать навыки ответов на вопросы), необходимо реализовать возможность генерации текста по заданному промпту. Допускается использование как старой модели rugpt3large_based_on_gpt2, так и новой ruGPT-3.5-13B.

Каждому студенту преподавателем будет дана пара слов, и требуется подобрать промпт таким образом, чтобы выданная пара слов встречалась бы в сгенерированном тексте с учётом порядка и с учётом словоформ (как в предыдущей работе). Подобранный промпт не должен содержать искомые слова ни в одной из их словоформ. Ограничений на значения параметров нет (даже на длину генерируемого текста и режим сэмплирования), но нельзя использовать LogitsProcessor.
